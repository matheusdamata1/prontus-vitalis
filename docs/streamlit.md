## 📊 Sobre a aplicação

O **Prontus Vitalis** possui uma aplicação interativa desenvolvida em **Streamlit** para exploração dos dados de atendimento hospitalar.

O dashboard permite:

* Filtrar os dados por período;
* Acompanhar indicadores hospitalares;
* Visualizar a evolução mensal das internações;
* Comparar municípios;
* Analisar o **Índice de Pressão Assistencial (IPA)**;
* Consultar o detalhamento de um município.

---

## 🖥️ Principais telas

### Visão geral

Apresenta os principais indicadores do período selecionado e os filtros disponíveis.

### Evolução mensal

Visualiza a variação das internações ao longo do período analisado.

### Índice de Pressão Assistencial

Apresenta a classificação dos municípios de acordo com o IPA desenvolvido no projeto.

### Ranking de municípios

Destaca os municípios com maior pressão assistencial.

### Detalhamento municipal

Permite consultar individualmente os principais indicadores de um município.
